# Workbench fonts

DM Mono and Martian Mono match the supplied workbench design. The TrueType
files are self-hosted, so the running application does not contact a font CDN.
The adjacent OFL files reproduce each font's SIL Open Font License.

Source CSS: `https://fonts.googleapis.com/css2?family=DM+Mono:wght@400;500&family=Martian+Mono:wght@400;500&display=swap`
Downloaded 2026-10-11 from the URLs in that CSS. License sources:

- `https://github.com/google/fonts/blob/main/ofl/dmmono/OFL.txt`
- `https://github.com/google/fonts/blob/main/ofl/martianmono/OFL.txt`
